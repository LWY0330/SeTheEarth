## 🔍 PM 关注点(已识别 / 不阻塞 LOCK)

### 关注点 1:Echo 状态数(5 vs 6)

- **现状**:
  - PROMPT 31(Khartoum Round 3,8/18)定义 **5 个状态**:default / hover / focus / typing / submitted
  - v1.3 spec §3.2 + §8.3 声称 **6 个状态**:default / hover / focus / typing / **disabled** / submitted
  - Echo 5 → 6 是 v1.3 spec 增补(增加 disabled 状态,如 rate-limited 时)
- **影响**:disabled 状态在 v1.2 PROMPT 31 实施时未交付,但 v1.3 spec 锁定为"6 状态必须"
- **PM 决议**:✅ **接受 v1.3 6 状态定义** — disabled 是合理设计(网络断/rate-limited/已提交后),后续 PROMPT 38 (Universal CityPage) 实施时需补 disabled 状态
- **行动项**:PM 在 Phase 2 任务清单(本 PM 已记录)中加注 "Echo disabled 状态 · Phase 2 first pass 必补"

### 关注点 2:Layer 色 HEX 微调

- **现状**:
  - v1.2 spec:`var(--earth-blue)` = `#4F8FE8`(浅蓝)
  - v1.3 spec §2.1.9:`var(--earth-blue)` = `#1A4D7E`(深蓝)— HEX 调整
  - Yellow / Red 保持 v1.2 原值
- **影响**:Earth Blue HEX 调整会**影响全局**(var(--earth-blue) 在 v1.2 spec 已有 5 处以上引用)
- **PM 决议**:🟡 **需 1 个 commit 验证 HEX 调整影响** — 在 alpha 分支跑 `grep -rn "var(--earth-blue)" src/` 看引用点 + Lighthouse QA
