## 1. 产品哲学

### 1.0 愿景（最高优先级 · 一切的出发点 · 藏在主标题的反面表达里）

> **「别把世界活的只有眼前这么小」**

**愿景的真正内涵**（由项目所有人 lwy 定义）：

> 打破信息茧房，让大家看见世界很大。同一时间，世界上在发生很多事情：
> 这一秒一个亿万富翁诞生，也有一个普通人失业；
> 有人在开车，有人在哭泣，有人在经历战火。
> 总之，**世界不止我们眼前的这点小事，不必为此烦恼**。

**主标题（v2.2.1）的正面表达**：「世界 · 不止方寸」—— 把"别活成方寸"反过来说。

**这是项目的灵魂**：做这个项目的**出发点**，设计这个项目的**基准**。无论是**文案**还是**算法**，都要基于这个愿景来搭建。

### 1.1 三大核心机制（愿景落地路径）

| 机制 | 含义 | v2.2 实现 |
|---|---|---|
| **同时性** | 同一时间，不同地方，不同命运 | 6 城市此刻叙事（编辑代写） |
| **去中心化** | 不放大单一视角，主动呈现"远方" | 6 城市编辑精选（铺满整个屏幕） |
| **释然感** | 让用户意识到"世界这么大，眼前的小事算什么" | 慢节奏 + 液态玻璃 + 大留白 |

### 1.2 五大设计原则

- ① 旅行手册感 → 升格为"此刻的世界"
- ② 有呼吸感（Breathable）
- ③ 液态玻璃（Liquid Glass · 不是 2020 毛玻璃）
- ④ 慢节奏（Slow > Fast）
- ⑤ 编辑精选，不堆砌（Editorial Curation）

### 1.3 v2.2 极简化原则

> 用户原话：**「只保留主文案和搜索框，简化视觉。把视觉重心放在后边的地点上」**

| 简化原则 | 含义 |
|---|---|
| **前景极简** | 只剩主标题 + 搜索框（去掉 eyebrow、副标题、focusBar、hint、奶白内容卡） |
| **背景主视觉** | 6 城市铺满整个屏幕，**地点**是视觉重心 |
| **文字要克制** | 城市玻璃信息条只保留城市名 + 此刻叙事（去掉"● 此刻 · 国家"装饰行） |
| **愿景藏在主标题** | 不再需要 eyebrow 喊"打破信息茧房"——主标题就是愿景本身 |

## 1.4 v2.2 → v2.2.1 变化记录

**主标题从 10 字 → 6 字，更简更有文学感。**

| 维度 | v2.2 | v2.2.1（当前） |
|---|---|---|
| 主标题 | 别把世界活的只有眼前这么小 | **世界 · 不止方寸** |
| 字数 | 10 字 | 6 字 |
| 结构 | 长句 | 「X · Y」两段式 |
| 强调词 | 眼前（普通） | **方寸**（经典文学意象） |
| 围绕愿景 | 直接引用 | **反面表达**（"别活成方寸" → "世界 · 不止方寸"） |
| 暖橘高亮 | 眼前两字 | **方寸两字** |

**为什么用「方寸」替代「眼前」**：
- "眼前"两字太普通，无美感
- "方寸"两字自带文学气场（"方寸之地"、"方寸大乱"、"方寸之间"全是经典）
- "方寸"是 v2.2 候选 A，用户最终确认

**「·」分隔符的设计意图**：
- 用户喜欢「不止 · 眼前」这种结构
- "·" 让两个概念"对比"和"递进"同时存在
- 6 字更有呼吸感，适合液态玻璃大字展示

## 1.7 v2.2.3 → v2.2.4 变化记录

**v2-E 模块升级为「事件驱动 + 城市随机推送」。**

| 维度 | v2.2.3 | v2.2.4（当前） |
|---|---|---|
| **城市** | 6 个固定（纽约/加沙/巴黎/东京/开普敦/雷克雅未克） | **20+ 城市池**（含伦敦/上海/京都/莫斯科/里约等） |
| **事件** | 6 个固定 | **60+ 事件**（每个城市 3 个不同类型的此刻） |
| **variant 匹配** | 城市 → variant（固定） | **event.category → variant**（动态） |
| **推送方式** | 静态（首屏固定） | **每 4.5 秒随机换 1 张**（动态推送） |
| **切换动画** | 无 | **600ms ease-emphatic**（淡入 + 上移 + blur 效果） |

### 推送机制

```ts
// src/hooks/useLiveMoments.ts
const { moments } = useLiveMoments({
  count: 6,         // 6 张卡
  intervalMs: 4500, // 每 4.5 秒推送一次
  swapPerTick: 1,   // 每次换 1 张
});
```

**推送时序**：
- 0s：初始 6 张随机事件
- 4.5s：随机 1 张换成新事件
- 9.0s：再换 1 张
- ...

**切换动画**（CSS keyframe）：
```css
@keyframes momentSwapIn {
  0%   { opacity: 0; transform: translateY(16px) scale(0.96); filter: blur(4px); }
  100% { opacity: 1; transform: translateY(0) scale(1); filter: blur(0); }
}
```

## 8. 首页版式（v2.2 · 极简版式）

```
┌──────────────────────────────────────┐
│  ● 看见地球                          │  ← header (极简)
│                                      │
│  [京]   [里斯本]   [上海]              │  ← 6 城市铺满整个屏幕
│                                      │     (主视觉：地点)
│         别把世界活的只有眼前这么小    │  ← 主标题（Fraunces 大字）
│       ┌────────────────────┐         │
│       │ 🔍 搜索城市    ↵   │         │  ← 搜索框（液态玻璃）
│       └────────────────────┘         │
│                                      │
│  [墨]   [雷]     [开]                │  ← 6 城市继续
│                                      │
│         6 座城市 · 此刻快照           │  ← footer
└──────────────────────────────────────┘
```

**关键设计**：
- **前景极简**：只有主标题 + 搜索框（无内容卡包装）
- **背景主视觉**：6 城市铺满整个屏幕
- **可读性保障**：主标题 text-shadow + 中央 vignette 蒙版
- **液态玻璃搜索框**：浮在城市图上，背后透出城市图（效果保留）

**z-index 层级**：
- `--z-bg` (0)：6 城市网格
- vignette (1)
- `--z-content` (3)：header / hero / footer
